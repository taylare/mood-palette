# mood-palette

Pick a vibe and get a five colour palette that matches the mood. Lock the colours you like, regenerate the rest with the spacebar, copy hex codes in one click and save your favourites.

Live site: https://taylare.github.io/mood-palette/

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` builds the app and deploys it to GitHub Pages using `.github/workflows/deploy.yml`.
